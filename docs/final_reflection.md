# Final Reflection

## 1. How does Git help in maintaining research traceability?
Git records every change made to a file along with who made it, when, and why
(via commit messages). This creates a full audit trail of the research process,
allowing researchers to revisit earlier decisions, understand why a method was
changed, and prove the integrity of their work.

## 2. Why is GitHub useful for academic collaboration?
GitHub allows multiple researchers to work on the same project simultaneously
using branches and Pull Requests. It provides a central location for code,
data, and documentation, making it easy to share work with supervisors,
co-authors, and the wider research community.

## 3. Why should researchers create branches instead of working directly on main?
Working directly on main risks breaking a stable, working version of the project.
Branches allow researchers to experiment, add features, or fix issues in
isolation. If something goes wrong, the main branch remains unaffected and
can be restored easily.

## 4. What is the role of Pull Requests in collaborative work?
Pull Requests provide a structured review process before changes are merged
into the main branch. They allow collaborators or supervisors to review,
comment on, and approve changes, ensuring quality control and knowledge
sharing across the team.

## 5. Why are reproducibility files important in research repositories?
Reproducibility files (requirements.txt, methodology.md, reproducibility_checklist.md)
ensure that any researcher can re-run the exact same experiment and obtain the
same results. This is a fundamental requirement of scientific integrity and
peer review.

## 6. What is the purpose of creating a version tag such as v1.0.0?
A version tag marks a specific, stable snapshot of the repository. In research,
this is critical when submitting a paper, referencing an experiment in a thesis,
or sharing a reproducible baseline. It ensures the cited version of the code
never changes even as the project evolves.

## 7. Why should a repository include a citation file?
A CITATION.md file makes it easy for other researchers to correctly credit
the work. As research software and datasets become publishable outputs,
proper citation ensures academic credit is given and enables others to
find and verify the original source.

## 8. How does this semester's Git/GitHub workflow support better PhD research practice?
This workflow mirrors real PhD research practice by enforcing structured
documentation, version control, peer review via Pull Requests, and reproducibility
standards. It builds habits that are directly transferable to managing thesis
experiments, collaborating with supervisors, and preparing code for publication.
